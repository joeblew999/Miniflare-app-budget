# Miniflare-app-budget

Example Google drive like app that will be able to run on Cloudflare using mitigate primitives

---

## Baht & Dollar Budget

Income and expenses in THB or AUD, any frequency, with shared tags. Every total shows both currencies.

Stack: React 19 + Vite + Tailwind v4 + shadcn/ui (radix-nova style, Neutral base, Green accent),
served as static assets from a Cloudflare Worker.

## Tasks (mise)

    mise run dev        # Vite with hot reload, http://localhost:5173
    mise run preview    # build, then run in Cloudflare's local runtime, http://localhost:8787
    mise run deploy     # build and deploy to Workers
    mise run ui:add dialog   # add shadcn components via the pinned shadcn CLI

## Layout

- `src/lib/budget.ts` — data model, conversions, localStorage load/save
- `src/App.tsx` — the UI
- `src/components/ui/` — shadcn components (generated by the CLI, edit freely)
- `src/index.css` — theme tokens (shadcn CSS variables, light + `.dark`)

## Theme

The theme is an official shadcn preset: **`b2oDXH5AO`** — base colour neutral, theme green, chart colour green,
Geist font, Lucide icons, nova style. Open it in the builder: https://ui.shadcn.com/create?preset=b2oDXH5AO

    mise run theme:show          # what preset the project is on
    mise run theme <code>        # switch to another preset (build one at ui.shadcn.com/create)

Applying a preset rewrites the CSS variables in `src/index.css` and reinstalls the components in
`src/components/ui/`, so don't hand-edit colours there. Light/dark follows the system setting
(`src/main.tsx` toggles the `.dark` class).

Available values (from the shadcn CLI): base colours neutral, stone, zinc, gray, mauve, olive, mist, taupe;
themes and chart colours amber, blue, cyan, emerald, fuchsia, green, indigo, lime, orange, pink, purple,
red, rose, sky, teal, violet, yellow, plus the base colours.
